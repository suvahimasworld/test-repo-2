**test-repo-2** is maintained under the **suvahimasworld** account and was initialized via the GitHub REST API. It's used as a workspace for experimenting with repository automation — creation, file commits, and content updates — all driven from the command line.

## 🚀 Getting Started

## 🛠️ How This Repo Is Managed

- **Created with:** GitHub REST API (`POST /user/repos`)
- **Commits pushed via:** GitHub Contents API (`PUT /repos/.../contents/...`)
- **Automation:** scripted end-to-end, no manual web UI steps
